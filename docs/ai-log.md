### Output

All files under `src/`, plus `app.json`, `.gitignore`, `.env.example`, `README.md`, the diagrams in `docs/diagrams/` (generated by `make_diagrams.py`), the screenshots in `docs/screenshots/` and the draft report `docs/StudyPulse-Phase1-Report.docx`.
The full code is the first commit on branch `feature/phase1-ui`.

Main design decisions the AI proposed:
- Provider pattern (React Context) with a feature-first `src/features/tasks` folder; thin Expo Router route files.
- Validation as a pure function (`validateTask()` in `validation.ts`), form state in a `useTaskForm()` hook.
- AsyncStorage behind a `taskRepository`, under the versioned key `studypulse/tasks/v1`.
- 8 functional requirements; FR7 (notifications) and FR8 (Google Calendar) planned for Phase 2.

### Checks run while the code was generated

- `npx tsc --noEmit` and `npx eslint src`: no errors.
- Fixed during generation: React Native 0.88 renamed the TextInput ref type (`TextInputInstance`); `Tabs` moved to `expo-router/tabs` in SDK 58; React Compiler lint rules (no reading refs during render, no setState directly in an effect); saving from a directly opened form had no screen to go back to; the tab labels were clipped on web.
- Tested in the browser (Expo web, phone-sized window): validation messages for every rule, focus moving to the first invalid field, adding, editing, deleting with confirmation, marking done, search, status and type filters, and data surviving a reload.
